一、核心 AI 辨識能力

YOLO26n 物件偵測 + 像素分析

1. 斑馬線精準定位

透過輕量化 YOLO 模型於街景照片中框選出 crosswalk（行人穿越道）區域，並計算模型信心百分比。

2. 標線物理狀態分析

針對最高信心斑馬線裁切原圖像素，利用灰階分佈直方圖與亮度均值評估標線褪色、磨損及現場能見度。

3. 駕駛視角空間評估

依據邊界框在影像中的相對位置與高度佔比，檢核斑馬線是否過於貼近車頭盲區或產生近距離空間壓迫。

4. 風險分級與處置建議

彙整五項硬體與環境指標為 0～7 分制風險等級，自動針對異常項目列出對應的養護或行車警示建議。

畫面標註圖例： 綠色外框（#00FF00）代表偵測到的 crosswalk（斑馬線） 標籤格式 crosswalk XX%：數值為模型對此區域屬於斑馬線的信心程度（僅顯示信心 ≥ 40% 之結果）

二、評估標準與風險分級（預設門檻值）

門檻為教學示範暫定值，可於測試區微調

當畫面存在多條斑馬線時，系統自動選取信心最高的一條，自原始未畫框影像裁切並縮放至最長邊 256 像素後轉灰階（0.299R + 0.587G + 0.114B）計算下列指標：

2. 框內能見度 所有街景照片 框內像素平均灰階值（0～255） 70 ～ 200 40～70 或 200～230 < 40（過暗）或 > 230（過曝）
3. 完整度 所有街景照片 框四邊距影像邊緣是否 < 對應邊長 2% 四邊皆未貼邊 任一側貼近邊緣（記錄貼邊方位） —（最高 1 分）
4. 視線盲區 限駕駛視角 底邊距離比例 = (圖高 - (y + h)) / 圖高 比例 ≥ 0.18（預設） 比例 < 0.18（預設） —（最高 1 分）

三、交通風險與辨識場景對照

七大常見路況解析
風險類別 典型辨識場景 偵測方式與系統判定結果
標線褪色或磨損 白漆剝落、瀝青鋪面反光接近標線顏色、長期輾壓導致紋理模糊。 計算框內灰階 P90 - P10 對比度；低於門檻時判為 1～2 分，提示需重新繪製標線。
光線過暗或過曝 夜間無路燈、樹蔭陰影覆蓋，或正午強光直射造成路面死白反光。 統計框內平均灰階亮度；偏離 70～200 區間即給 1～2 分，警示能見度不足。
斑馬線被切掉或遮住 鏡頭角度偏斜、車距過近或前車遮擋，使斑馬線貼近畫面四週邊界。 檢查偵測框是否距離畫面左、右、上、下任一邊緣小於 2%，貼邊即計 1 分。
視線盲區 車輛已逼近停止線或斑馬線前緣，標線落入引擎蓋前緣視覺死角區。 計算框底邊至畫面底部距離比例，小於 0.18 計 1 分，提醒駕駛留意車頭盲區。
空間壓迫 緊貼前車或高速逼近路口，斑馬線在垂直視野中佔據過大面積。 計算框高度佔整張圖高度比例，大於 0.25 計 1 分，顯示緩衝空間不足。
綜合分級 同時出現「夜間昏暗 + 標線磨損 + 逼近路口」等多重不利條件。 加總五項得分（0～7 分），依低、中、高風險標籤呈現整體危險等級。
未偵測到斑馬線 標線完全磨滅、被積水/落葉覆蓋，或拍攝角度未拍到行人穿越道。 信心分數皆低於 0.4，顯示灰色「無法評估」標籤並建議現場核查或重拍。

四、系統邊界與尚未支援項目說明

單一類別硬體巡檢模型

本系統載入之 best.onnx 為專注於靜態道路標線（crosswalk）的單類別偵測模型，下列動態交通要素與違規行為目前均不支援：

  • 交通號誌與燈號顏色：無法辨識紅綠燈、行人倒數計時器或閃光號誌狀態。
  • 用路人與車輛物件：不具備行人、汽機車、自行車或車牌號碼偵測能力。
  • 動態交通違規舉發：無法判定「路口未禮讓行人」、「違規臨時停車」或「機車騎士未戴安全帽」等行為類違規。

※ 若未來需擴充上述功能，須重新蒐集對應街景資料集、新增標註類別並重新訓練多類別 YOLO 模型後替換 best.onnx。

五、模型開發流程與核心技術特色

端到端邊緣 AI 架構
STEP 01

Roboflow 資料標註

蒐集多天候與多角度街景照片，框選 crosswalk 並進行資料增強與切分。

STEP 02

Google Colab 訓練

使用 Ultralytics YOLO26n 架構進行遷移學習訓練，收斂並驗證 mAP 指標。

STEP 03

匯出 ONNX 格式

將權重轉換為固定輸入 [1, 3, 640, 640] 的 best.onnx 模型檔。

STEP 04

瀏覽器前端推論

透過 ONNX Runtime Web 執行 letterbox 前處理、單類別 NMS 與像素評分。

純地端推論（隱私零外流）

所有影像解碼與神經網路運算皆在使用者裝置瀏覽器記憶體完成，街景照片絕不上傳至任何外部伺服器。

YOLO 精準空間標定

維持原圖長寬比進行等比例縮放與灰邊填充（Letterbox），還原真實座標並過濾重疊候選框。

像素分析與評分決策引擎

結合幾何位置與原圖灰階統計量，將視覺特徵轉化為可解釋、可調整門檻的量化風險指標。

開發者微調提示：所有評分門檻皆集中定義於本網頁 <script> 區塊最上方的 DEFAULT_THRESHOLDS 常數物件中，可直接修改程式碼常數或透過下方測試區的即時滑桿進行實驗。
